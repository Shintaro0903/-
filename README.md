# SPIRITS ご注文サイトの更新方法

このリポジトリは GitHub Pages で公開している、株式会社オーリックの毎月のウイスキーご注文サイトです。
`https://shintaro0903.github.io/-/` で公開されています。

## ファイル構成

- `index.html` … サイトの見た目・動作（通常は触らなくてOK）
- `data.json` … 号数・商品情報など、毎月変える中身
- `images/` … 商品のボトル写真

毎月の更新は基本的に `data.json` の中身を書き換えることと、`images/` フォルダの写真を差し替えることだけで完結します。

## 1. 号数・日付を変える

`data.json` の一番上、`"issue"` の部分を書き換えます。

```json
"issue": {
  "no": "NO 2026,7,16",
  "lotteryDate": "2026/7/31",
  "expiryDate": "2026/8/15"
},
```

- `no`：チラシの号数・発行日表示
- `lotteryDate`：抽選日
- `expiryDate`：ご注文有効期限

## 2. 商品を編集する

`"products"` の配列に、商品が1つずつオブジェクト（`{ ... }`）として並んでいます。既存の1件をコピーして書き換えるのが一番安全です。

```json
{
  "n": 1,
  "code": "282027",
  "name": "ザ・ラッキーキャット ソラ 43%",
  "origin": "日本（長野県）",
  "type": "ブレンデッドウイスキー",
  "vol": "700ml",
  "desc": "商品説明文をここに入れます。",
  "price": 5720,
  "img": "product01"
}
```

- `n`：商品番号（バッジに表示される番号）
- `code`：商品CD
- `name` / `origin` / `type` / `vol` / `desc`：商品名・産地・タイプ・内容量・説明文
- `price`：価格（数字のみ。カンマや¥は不要）
- `img`：`images/` フォルダ内の画像ファイル名（拡張子 `.jpg` は書かない）

商品を増やしたいときは `{ ... }` のブロックをまるごとコピーして、カンマ区切りで追加してください。減らしたいときはブロックを削除してください（前後のカンマの数に注意）。

## 3. 特集商品（今月のおすすめ）を変える

`"special"` の中身を同じ要領で書き換えます。`specLines` は商品スペックを1行ずつ配列で並べたものです。

## 4. ボトル写真を差し替える

1. `images` フォルダを開く
2. 差し替えたい画像ファイル（例：`product01.jpg`）をクリック
3. 右上のゴミ箱アイコンで削除してコミット、その後「Add file」→「Upload files」で新しい写真を同じファイル名（例：`product01.jpg`）でアップロードしてコミット
   - もしくは、そのまま「Add file」→「Upload files」で同名ファイルをアップロードすると上書きの確認が出るので、それでもOKです
4. `data.json` 側の `"img"` の値（拡張子なしのファイル名）が正しく対応していることを確認

新しい商品用に写真を追加する場合は、`images` フォルダに新しいファイル名（例：`product13.jpg`）でアップロードし、`data.json` の `"img"` にその名前（`product13`）を指定してください。

## 5. 保存（コミット）のしかた

`data.json` を編集する場合も、鉛筆アイコンで開いて直接編集し、画面上部の「Commit changes...」→「Commit directly to the main branch」を選んで保存します。保存後、1分ほどでサイトに反映されます。

## 注意点（JSONの書き方）

- 文字列は必ず `"..."` で囲む
- 各項目の末尾には基本的にカンマ `,` が必要（ただし配列やオブジェクトの一番最後の項目にはカンマを付けない）
- 保存後にサイトを開いて商品が表示されない・真っ白でエラーメッセージが出る場合は、直前の編集にカンマや引用符の閉じ忘れがないか確認してください
- 分からなくなった場合は、ファイルの「History」から一つ前のバージョンに戻すこともできます

## ご注文の送信先メールアドレスを変える

`data.json` の `"orderEmail"` の値を書き換えてください。
