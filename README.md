# SPIRITS ご注文サイトの更新方法

このリポジトリは GitHub Pages で公開している、株式会社オーリックの毎月のウイスキーご注文サイトです。
`https://shintaro0903.github.io/-/` で公開されています。

## ファイル構成

- `index.html` … サイトの見た目・動作（通常は触らなくてOK）。A4両面印刷機能も含まれています
- `data.json` … 号数・商品情報など、毎月変える中身
- `images/` … 商品のボトル写真
- `editor.html` … **`data.json` をフォーム入力だけで作れる編集ツール（毎月の更新はこれを使うのがおすすめです）**

## おすすめの更新方法：editor.html を使う

JSONを直接書き換えるとカンマや引用符のミスでサイトが表示されなくなることがあるため、`editor.html` を使うことをおすすめします。

1. `editor.html` をパソコンにダウンロードして、ダブルクリックでブラウザで開く（GitHubにアップロードしなくても、手元で開くだけで使えます）
2. 開くと直近の号数・商品情報がすでに入力された状態になっています。号数・抽選日・有効期限、各商品の商品名・価格・説明文などを今月の内容に書き換える
   - 商品を増やしたいときは「＋ 商品を追加」
   - 商品を減らしたいときは各商品の「削除」
   - 順番を変えたいときは「↑」「↓」
3. ページ下部の「data.json をダウンロード」を押すと、正しい書式の `data.json` がダウンロードされます
4. GitHubのリポジトリで、今の `data.json` をダウンロードしたファイルに差し替えてコミットする（下記「保存（コミット）のしかた」参照）
5. ボトル写真を変える場合は、`images` フォルダに新しい画像を同じファイル名でアップロードする（editor.html で画像を選ぶとファイル名の目安が自動入力されますが、画像ファイル自体は別途GitHubにアップロードが必要です）
6. 1〜2分待ってサイトを確認する

前月の `data.json` を先に読み込んでから編集したい場合は、`editor.html` 上部の「既存データの読み込み」でGitHubからダウンロードした `data.json` を選択してください。

## 保存（コミット）のしかた（GitHub上での操作）

1. リポジトリのコード画面で `data.json` をクリック
2. 右上の鉛筆アイコンで編集画面を開く
3. 中身を全選択して削除し、`editor.html` でダウンロードした新しい `data.json` の中身を貼り付ける
   - または、一度 `data.json` を削除してコミットし、「Add file」→「Upload files」でダウンロードしたファイルをアップロードする方法でも構いません
4. 画面上部の「Commit changes...」→「Commit directly to the main branch」を選んで保存する

## data.json を直接編集する場合（上級者向け）

`editor.html` を使わずに直接 `data.json` を編集することも可能です。以下、参考までに構造を説明します。

### 号数・日付

```json
"issue": {
  "no": "NO 2026,7,16",
  "lotteryDate": "2026/7/31",
  "expiryDate": "2026/8/15"
},
```

### 商品

```json
{
  "n": 1,
  "code": "282027",
  "name": "ザ・ラッキーキャット ソラ 43%",
  "origin": "日本（長野県）",
  "type": "ブレンデッドウイスキー",
  "vol": "700ml",
  "desc": "商品説明文をここに入れます。",
  "price": 5720,
  "img": "product01"
}
```

- `n`：商品番号（バッジに表示される番号）
- `code`：商品CD
- `price`：価格（数字のみ。カンマや¥は不要）
- `img`：`images/` フォルダ内の画像ファイル名（拡張子 `.jpg` は書かない）

### 注意点（JSONの書き方）

- 文字列は必ず `"..."` で囲む
- 各項目の末尾には基本的にカンマ `,` が必要（配列やオブジェクトの一番最後の項目にはカンマを付けない）
- 保存後にサイトを開いてエラーメッセージが出る場合は、直前の編集にカンマや引用符の閉じ忘れがないか確認するか、ファイルの「History」から一つ前のバージョンに戻してください

## ボトル写真を差し替える

1. `images` フォルダを開く
2. 差し替えたい画像ファイル（例：`product01.jpg`）をクリックし、右上のゴミ箱アイコンで削除してコミット
3. 「Add file」→「Upload files」で新しい写真を同じファイル名（例：`product01.jpg`）でアップロードしてコミット
4. `data.json`（または `editor.html`）側の画像ファイル名（拡張子なし）が正しく対応していることを確認

## ご注文の送信先メールアドレスを変える

`editor.html` の「ご注文の送信先メールアドレス」欄、または `data.json` の `"orderEmail"` の値を書き換えてください。

## 月末など、一時的にご注文を停止したいとき

月末に来月分の商品を選定している間など、サイトを一時的に「ご注文停止」の状態にできます。商品一覧やご注文フォームの代わりに、案内メッセージだけが表示されます。

- `editor.html` を使う場合：「3. 公開状態」のチェックボックス「現在、商品選定中としてご注文を停止する」にチェックを入れ、必要であれば案内メッセージを書き換えてから、いつも通り `data.json` をダウンロードしてアップロードしてください。
- `data.json` を直接編集する場合：`"closed": true` にし、`"closedMessage"` にお客様へ表示したい文章を入れてください。

新しい商品が決まったら、チェックを外す（または `"closed": false` に戻す）だけで通常表示に戻ります。

## 印刷する（FAX注文用の紙として使いたいとき）

サイト上部に印刷用のボタンが2種類あります。中身はどちらも常に `data.json` の最新内容と連動しているので、Web注文用の画面と印刷した紙面が食い違うことはありません。

- **🖨 A4 1枚にまとめて印刷する** … 特集商品＋全商品を、文字を小さめにしてA4用紙1枚（片面）にすべて収めます。省スペースで、1枚だけ配りたい・保管したいときに便利です。
- **🖨 この内容をA4両面（2枚）で印刷する** … 特集商品＋商品を前半・後半に分けて、A4サイズ2ページ（表・裏）に、文字を大きめ・見やすくレイアウトします。両面印刷にすれば紙1枚（表裏）に収まります。

### 使い方

1. サイトを開き、お好みのボタンを押す
2. ブラウザの印刷画面が開くので、以下を確認する
   - 用紙サイズ：A4
   - 余白：デフォルト（またはブラウザ側の「印刷設定」の指定に従う）
   - ページ数（1枚を選んだ場合は1ページ、両面を選んだ場合は2ページ）になっているか確認する
3. 「A4両面（2枚）」を選んだ場合、お使いのプリンターが両面印刷に対応していれば、印刷画面の詳細設定で「両面印刷」（Chromeの場合は「詳細設定」の中）をオンにして印刷すると、1枚の紙の表裏に自動で印刷されます
4. 両面印刷に対応していないプリンターの場合は、片面ずつ2回に分けて印刷し、1ページ目を印刷した用紙を裏返してもう一度給紙トレイにセットしてから2ページ目を印刷してください（プリンターの説明書に「手動両面印刷」の手順があれば、それに従ってください）

印刷される紙面には、各商品の横に手書きで本数を書き込める枠と、下部にFAX注文用の記入欄（貴店名・ご担当者様・TEL）も入っています。

## お客様への自動返信メールを設定する（EmailJS）

現在は「送信ボタンを押すとお客様自身のメールソフトが開く」方式（mailto）ですが、無料の [EmailJS](https://www.emailjs.com/) に登録すると、ボタン一つでその場から送信され、お客様にも自動で確認メールが届くようにできます。設定するまでは、これまで通りmailto方式で動作するので、急いで設定する必要はありません。

### 1. EmailJSに登録してメールサービスを連携する

1. https://www.emailjs.com/ で無料アカウントを作成する
2. 左メニュー「Email Services」→「Add New Service」で、ふだん使っているメール（Gmailなど）を連携する
3. 作成された Service の **Service ID** を控えておく

### 2. テンプレートを2つ作成する

左メニュー「Email Templates」→「Create New Template」で、以下を2つ作成します。作成後、それぞれの **Template ID** を控えておいてください。

**テンプレート1：店舗宛の注文通知**

- To email：`{{to_email}}`
- Reply To：`{{customer_email}}`
- Subject：`【ご注文】SPIRITS {{issue_no}} - {{shop_name}}様`
- Content（本文）：

```
貴店名：{{shop_name}}
ご担当者様：{{person_name}}
TEL：{{tel}}
メール：{{customer_email}}

【ご注文内容】
{{order_lines}}

合計本数：{{total_count}}本
合計金額（税込目安）：{{total_price}}
```

**テンプレート2：お客様宛の自動返信**

- To email：`{{customer_email}}`
- Reply To：（オーリックの受注メールアドレス）
- Subject：`【株式会社オーリック】ご注文を受け付けました（SPIRITS {{issue_no}}）`
- Content（本文）：

```
{{shop_name}} {{person_name}} 様

この度はご注文いただき誠にありがとうございます。以下の内容で承りました。

【ご注文内容】
{{order_lines}}

合計本数：{{total_count}}本
合計金額（税込目安）：{{total_price}}

内容に相違がございましたら、本メールにご返信いただくか、TEL 092-731-0296までご連絡ください。

株式会社オーリック
```

### 3. Public Keyを確認する

左メニュー「Account」→「General」に表示されている **Public Key** を控えておきます。

### 4. editor.html に入力する

`editor.html` の「4. 自動返信メールの設定（EmailJS）」に、控えておいた4つの値を入力します。

- Service ID
- Public Key
- Template ID（店舗宛通知用） … テンプレート1のID
- Template ID（お客様宛自動返信用） … テンプレート2のID

入力したら、いつも通り `data.json` をダウンロードしてGitHubにアップロードしてください。あわせて、今回お送りした最新版の `index.html` もアップロードされているか確認してください（自動返信の仕組みはこちらに入っています）。

設定後は、ご注文フォームに「メールアドレス」欄が表示され、送信ボタンを押すとその場で店舗宛の通知とお客様への自動返信の両方が送信されます。4つの値のいずれかが空欄の場合は、自動的に今まで通りのmailto方式で動作します。
